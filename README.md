# react-native-fortress

Native-first mobile security for React Native: anti-tampering, root/jailbreak detection, SSL pinning

## Installation


```sh
npm install react-native-fortress
```


## Usage


```js
import { multiply } from 'react-native-fortress';

// ...

const result = multiply(3, 7);
```
